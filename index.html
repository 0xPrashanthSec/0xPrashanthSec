  • HIGHjava_child_download_encoded.tomlJava Child Process with Download or Encoded CommandEQL · windows

Exploitation of Java applications and services (for example deserialization, expression-injection or JVM vulnerabilities such as CVE-2026-114938) commonly results in the JVM spawning a shell to download and run a second-stage payload.

    mitre = T1059.001 PowerShell · T1059.003 Windows Command Shell · T1190 Exploit Public-Facing Application · T1105 Ingress Tool Transfer

    process where host.os.type == "windows" and event.type == "start" and
  process.parent.name : ("java.exe", "javaw.exe") and
  (
    process.name : (
